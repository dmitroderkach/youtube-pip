Claude token: who holds it, who gets what

The year-long subscription token (claude setup-token) never reaches Claude Code: a small proxy next to it adds the token to each API request.
Dev worker · ECS task

🔐 Secrets Manager

youtube-pip-oncall: claude_code_oauth_token

↓ real token (task start)

💻 worker.mjs · user devworker

Gets the real token from the task at start. Runs the proxy inside its own process.

🔁 token proxy · 127.0.0.1:<random port>

anthropic-proxy.mjs. A new random placeholder at every start.

✔ request with the placeholder → placeholder replaced by the real token → api.anthropic.com

✖ any other token → 401, nothing forwarded (other local users cannot use it)

• no token at all (connectivity check) → forwarded without a token

↑ API requests with the placeholder

🧠 Claude Code · user worker

Its environment: ANTHROPIC_BASE_URL = the proxy, CLAUDE_CODE_OAUTH_TOKEN = the placeholder.

🚫 Cannot read the real token: it lives in a process of another Linux user (/proc/<pid>/environ is closed).

On-call job · Fargate runner

🔐 Secrets Manager

youtube-pip-oncall: claude_code_oauth_token

↓ real token (task start)

⚙️ job steps · user runner

Gets the real token from the task. run-agent.sh starts the proxy as this user.

🔁 token proxy · 127.0.0.1:<random port>

anthropic-proxy.mjs. A new random placeholder at every start.

✔ request with the placeholder → placeholder replaced by the real token → api.anthropic.com

✖ any other token → 401, nothing forwarded (other local users cannot use it)

• no token at all (connectivity check) → forwarded without a token

↑ API requests with the placeholder

🔎 on-call agent · user oncall-agent

The same two variables, nothing else. Read / Grep / Glob, no shell, no network tools.

🚫 Cannot read the real token: it lives in a process of another Linux user (/proc/<pid>/environ is closed).

☁️ api.anthropic.com → with the real token

Sees the real token, the same requests as before.

What a prompt injection could take: Before

The real token from the environment: a year of your subscription, usable anywhere.

What a prompt injection could take: Now

Only the placeholder: worthless outside, dies with the worker run / the job. At most it can spend the subscription through the proxy while that runs.

Same idea as the GitHub broker, but a proxy: Anthropic has no way to mint a short-lived token, so the real one never leaves the proxy's process.
